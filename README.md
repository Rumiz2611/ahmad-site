# Ahmad's homepage

A bilingual (English / Hebrew) personal portfolio built with HTML, CSS, and JavaScript in VS Code and published with GitHub Pages.

## Features

- Switch between English and Hebrew, with the page direction updating for each language.
- Responsive portfolio sections for the introduction, studies, projects, and contact information.
- Expandable project cards for the FPGA Frogger-inspired arcade game and Sobel edge-detection accelerator.
- Pixel-art screenshot of the FPGA game in its project card.
- Animated pixel-art cursor on mouse/trackpad devices, with a hand-tap animation on click. The regular cursor is retained for touch and reduced-motion preferences.

## Project files

- `index.html` – page structure, bilingual copy, and project details.
- `style.css` – layout, visual design, responsive behavior, and animations.
- `script.js` – language switching and custom cursor behavior.
- `images/` – project screenshots and diagrams.

## AI-assisted development

The site was developed in VS Code with assistance from GitHub Copilot and multiple AI models, including GPT and Luna. Copilot assistance was used to help shape and refine the portfolio content, bilingual presentation, project cards, pixel-art visuals, and cursor interaction. Ahmad guided the work, reviewed the changes, and tested the resulting site.

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension for a local preview.
